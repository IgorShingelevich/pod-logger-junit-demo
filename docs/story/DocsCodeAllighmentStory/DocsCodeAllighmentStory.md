Документ DOCS Code Alignment.md должен описывать процедуру сверки кода с состоянием главных документов, которые были приняты в устав проекта, встав фич, приема, commands, RIDMI и карту модулей по MD-шке на каждый модуль. Все эти документы должны быть связаны между собой с киллом, который будет триггериться пользователем с задачей сопоставить и сделать сопоставить все существующие уставные документы. И при запуске этого скилла должен формироваться свежий  отчет о Docs Code Alignment Result.  В документе Docs Code Alignment опиши, как должен работать этот скилл, и опиши также все критерии, по которым сопоставляется код и документация в фактическом состоянии. Делается расхождение: используй частные случаи расхождений для того, чтобы заранее создать список проверок в этом документе, что нужно проверить.


То есть, вызывая этот скилл, агент пойдет в Docs Code Alignment.md, прочитает, как и что нужно проверять, еще раз все сверит и в конце проверки породит документ Docs Code Alignment Result.
